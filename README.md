# Hotel Management System (Backend)

A Spring Boot REST API with MongoDB for managing hotel rooms, reservations and orders. Built as a group project.

## Features
- Room management
- Room reservations
- Orders and pending orders
- User management

## Tech Stack
- Java
- Spring Boot (Maven)
- MongoDB

## Project Structure
- `config`: application configuration (CORS)
- `controllers`: REST API endpoints
- `model`: data models
- `repositories`: database access layer

## How to Run
1. Clone the repo
2. Set your MongoDB connection string as an environment variable:
   `MONGODB_URI=your-mongodb-connection-string`
3. Run `./mvnw spring-boot:run`
4. The server starts on port `8081`
